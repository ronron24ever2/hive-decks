# Intralogistics Deck — Handoff to Tatiana

**Live URL:** https://presentations.hiveautonomy.no/intralogistics/
**Source repo:** github.com/ronron24ever2/hive-decks (folder: `intralogistics/`)

## Innhold
- `index.html` — hele decket (single-file HTML med inline CSS/JS)
- `presentation-assets/` — bilder og videoer referert fra decket

## Åpne lokalt
Dobbeltklikk `index.html` i Finder — åpnes i browseren. Alle videoer og bilder ligger relativt i `presentation-assets/` og fungerer offline.

## Tastaturnavigasjon
- Pil høyre / Space — neste slide
- Pil venstre — forrige
- F — fullskjerm

## Redigere
Åpne `index.html` i en editor (VS Code, Sublime, eller hva du foretrekker). Hver slide er en `<section class="slide">` blokk. Søk etter "SLIDE" eller slidenummer for å finne riktig sted.

For å bytte asset: legg ny fil i `presentation-assets/` og oppdater referansen i `index.html`.

## Deploy endringer tilbake
Ronny pusher til GitHub-repoet når du er ferdig. Send hele mappen (eller bare endrede filer) tilbake.
